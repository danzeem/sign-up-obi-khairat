# ObiKhairat Sign-Up Page

A clean, modern sign-up form for **ObiKhairat**, a concept charity platform for sharing gently used essentials.

**Live demo:** https://danzeem.github.io/sign-up-obi-khairat/

![Sign-up page](screenshots/sign-up.png)

## About

This is the sign-up screen that goes with my ObiKhairat project. The main application is a Java donation-management app (the code is kept private, with a README-only showcase in the [ObiKhairat](https://github.com/danzeem/ObiKhairat) repo).

It is a **front-end mockup built with HTML and CSS only**. There is no backend, so the form does not submit, store, or send any data. Please don't enter a real password.

## Features

- Centered card layout on a teal gradient background
- Fields for first name, last name, email address, and password
- Floating labels on the input fields
- Styled "Sign Up" button with terms and privacy policy notice
- "Already have an account? Sign in" link

## Tech stack

- HTML5
- CSS3

## Run locally

1. Clone the repo:
   ```bash
   git clone https://github.com/danzeem/sign-up-obi-khairat.git
   ```
2. Open `index.html` in your browser. No build step or dependencies needed.

## Limitations

- The form has no validation logic or server connection.
- "Sign in", "Terms", and "Privacy Policy" are placeholder links.
